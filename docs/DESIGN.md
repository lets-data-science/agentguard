# AgentGuard design

A small security workbench: paper canvas, ink typography, a clear network policy,
and a chronological record of actual sandbox requests. Match LDS: #171717 ink,
#fff paper, #f5f5f3 workspace, #e5e5e1 lines, #686862 secondary, #f6be35 action.
Use system sans, 8/16/24/32 spacing, no invented risk score or success result.
The primary action moves from connect → create sandbox → run checks → read evidence.
An unavailable gateway is a useful explicit state, never a simulated pass.
Mobile stacks policy above evidence. Color always has a text label.
